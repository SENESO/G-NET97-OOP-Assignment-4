# G-NET97 OOP — Assignment 4: Shipping System Model

C# console application modeling a shipping system with object-oriented design.

## Project Structure

- **Models/Shipments** — Shipment entity classes
- **Models/Centers** — Shipping center classes
- **Models/Relationships** — Relationships between entities
- **Models/Helpers** — Helper utilities

## How to Run

```bash
dotnet run
```

## Tech Stack

- C# / .NET
- Console Application
